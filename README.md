# 🚧 Fog-Adaptive Smart Streetlight & Heavy Vehicle Warning System for Hairpin Roads

### ⚡ A multi-system safety solution designed to reduce accidents in low-visibility and blind-curve road conditions.

---

## 📘 Project Context
This project was developed as part of a **3rd-year Electronics and Communication Engineering mini project**, focusing on solving real-world safety challenges in hairpin bend roads.

---

## 📌 Problem Statement

Hairpin bend roads, especially in hilly regions, are highly prone to accidents due to:
- Limited visibility caused by fog and weather conditions
- Blind curves preventing drivers from seeing oncoming vehicles
- Lack of intelligent traffic control systems
- No emergency detection or alert mechanisms

---

## 💡 Solution Overview

This project presents an integrated system that combines:

- Fog-adaptive street lighting
- Two-way heavy vehicle detection and warning system
- Emergency accident detection using ultrasonic sensing
- GSM-based alert system for real-time accident notification

The system is designed to improve road safety and provide real-time assistance in critical scenarios.
